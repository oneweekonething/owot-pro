# 垂类业务系统模块目录索引（09 ~ 19）

本目录用于存放构建在基础功能模块（`01-framework` + `02-base-modules`）之上的 **12 大垂类行业业务系统模块**独立技术文档：

- `09-module-mall.md`：B2C 电子商城系统（`product` 商品、`trade` 交易、`promotion` 营销、`statistics` 统计）
- `10-module-erp.md`：ERP 企业资源计划系统（产品、库存、采购、销售、财务结算）
- `11-module-wms.md`：WMS 专业仓库管理系统（仓库/库区/库位、出入移盘单据、冻结库存）
- `12-module-crm.md`：CRM 客户关系管理系统（线索、客户/公海池、商机、合同、回款、团队权限）
- `13-module-mes.md`：MES 制造执行系统（基础、生产排产报工/安灯、车间仓/SN、质检、设备、工装、排班）
- `14-module-hrm.md`：HRM 人力资源管理系统（组织、员工入转调离、招聘、考勤、社保、算薪个税、绩效）
- `15-module-fms.md`：FMS 财务管理系统（多账套、科目、辅助核算、复式记账凭证、账簿、三大报表、期末结账）
- `16-module-pms.md`：PMS 项目管理与知识库系统（项目中心敏捷迭代 Sprint、工作项看板、多级知识库协同）
- `17-module-oa.md`：OA 协同办公系统（日程/汇报/公告、企业邮箱、企业云盘、用品/用印/会议室/车辆、人事与公文流程）
- `18-module-ai.md`：AI 大模型平台（20+ 模型接入、流式对话/思考模式、绘画/音乐、RAG 知识库、工作流、MCP）
- `19-module-iot.md`：IoT 物联网平台（物模型 TSL、设备/影子/OTA、10 种协议接入网关、TDengine/IoTDB、场景联动）
- `20-module-im.md`：IM 即时通讯系统（好友/群组/频道、Sequence ID 离线漫游、WebRTC 音视频通话与屏幕共享）
